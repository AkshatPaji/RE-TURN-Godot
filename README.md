# RE:TURN - Godot

hola amigos, so remember [RE:TURN](https://akshatpaji.itch.io/return), the ping pong game i made during Haven@Chandigarh (goated event btw). well, i decided to remake it in godot because why not. the original was made using pygame and this time i wanted to try something new. did it go as planned? not really. is it playable? yes. did i learn something? hopefully.

anyways, this is my attempt at recreating RE:TURN in godot. still got alot to learn about godot and its 5000 different features but hey, one step at a time.

## How to play

really? u need guide for pong ping? ping Pong*.. jk jk

- Move the paddle with the **Up** and **Down** arrow keys.
- Hit the ball with the paddle. the bounce angle changes depending on where it hits.
- Score points by hitting the barrier on the right.
- Let the ball get past your paddle and well... game over. select **Restart** and try again.

## Features

- Paddle angle changes depending on its position and movement.
- Ball speed changes slightly after collisions and stays between 440 and 600.
- High score is saved between sessions in Godot's `user://high_score.cfg` file. because apparently we need to keep track of our ping pong achievements. btw forgot to delete mien and dont judge me cuz i never made it above 13 ig.. 15 maybe

## Run the game

1. Download/clone the project .zip from github.
2. Open the project in Godot 4 and press **F5** to run the game.
3. Or simply log onto [Itch.io : return-godot](https://akshatpaji.itch.io/return-godot) and play it directly on the web. much easier, ik.
